Questa cartella (Components) serve a contenere i "pezzi" riutilizzabili dell'interfaccia utente (file HTML, CSS o JS).
Cosa inserire qui:
- Una barra di navigazione laterale (es. sidebar.js / sidebar.css)
- La barra superiore (navbar)
- Modali o popup che usi in più pagine
- Il footer (piè di pagina)

L'idea è scrivere il codice di questi elementi una sola volta qui dentro, per poi riutilizzarlo in tutte le "pages" dove serve!
