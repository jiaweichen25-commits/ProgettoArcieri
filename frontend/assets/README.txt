Questa cartella (Assets) contiene tutti i file statici visivi che non sono propriamente "codice logico".
Cosa inserire qui:
- Immagini e foto (.png, .jpg, .webp)
- Loghi e icone (.svg)
- Eventuali font scaricati
- File audio/video se necessari

Mantenerli separati ti aiuta a non confondere il codice con le risorse multimediali.
