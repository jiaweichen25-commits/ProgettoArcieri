Questa cartella (Repositories) è l'UNICO posto in cui dovresti scrivere query SQL dirette (SELECT, INSERT, UPDATE, DELETE).
Cosa inserire qui:
- Funzioni che si collegano al DB.
- Funzioni per cercare un utente tramite email.
- Funzioni per inserire un nuovo utente.
Il repository non prende decisioni logiche, prende semplicemente i dati dal DB e li passa al "service".
